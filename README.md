## ✦ about

**xiive studio** is an independent digital playground focused on building polished, unusual, and deeply interactive experiences.

The site serves as the home for xiive projects — from experimental games to web experiences, tools, prototypes, and future releases.

---

## ◈ featured project — Basilisk

**Basilisk** is a competitive cave-hunting game built around exploration, incomplete information, hazards, searching, and a rival hunter navigating the same underground network.

Basilisk currently includes:

- native macOS builds
- native Windows builds
- browser play
- multiplayer
- procedural cave systems
- exploration and hidden information
- competitive hunter gameplay

## ◉ xiive assistant

The site includes **xiiveBot**, a lightweight guided assistant designed to adapt to the project currently being viewed.

On the Basilisk page, xiiveBot can help visitors:

- report bugs
- leave reviews
- install Basilisk
- launch the browser build
- get gameplay help
- contact xiive

The long-term goal is for the assistant to become a shared navigation and support layer across the entire xiive ecosystem.
